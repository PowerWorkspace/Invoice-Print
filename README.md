# Invoice-Print 发票合并打印工具

基于 aardio 开发的发票合并打印工具。

## 运行时依赖

本工具处理 PDF 时需要 MuPDF 的 `mutool.exe`（约 46MB）。该文件体积较大，不纳入 Git 仓库，改为通过 Gitee Releases 分发：

- 下载地址：<https://gitee.com/powerclub/Invoice-Print/releases/tag/runtime-deps>
- 将下载的 `mutool.exe` 放入项目 `res/` 目录后，即可正常构建与运行。
